# Video assets

Drop real `.mp4` / `.webm` files here using the exact filenames below and they
will appear automatically — no code changes required. Until a file exists, the
site renders a cinematic CSS/gradient fallback in its place (see
`src/components/MediaBackground.tsx`).

Keep files web-optimized: H.264/AAC `.mp4` (or VP9 `.webm`), muted, short loops,
ideally under ~6 MB so they stay performant. All footage must depict adults
(21+) only and avoid showing intoxication or irresponsible behavior.

| Filename                | Used on            | Concept                                           |
| ----------------------- | ------------------ | ------------------------------------------------- |
| `copper-still.mp4`      | Home hero          | Copper still steam / distillation close-up        |
| `cocktail-pour.mp4`     | Bar hero           | Slow cocktail pour over ice                       |
