# Image assets

Drop real photos here at the exact paths below and they replace the generated
art / gradients automatically — every `<img>` has an `onError` fallback, so a
missing file degrades gracefully to a cinematic placeholder.

Recommended: optimized `.jpg`/`.webp`, ~1600–2400px on the long edge for heroes,
~1000px for cards. Any people shown must clearly be adults (21+). No depictions
of intoxication, underage drinking, or drinking-and-driving.
